# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、本地保存和导出JSON。

## 洗缩校准

登记样片的经纬密、坯布与洗后宽长、样片编号，系统自动算出缩率，并可按成品尺寸反推织造网格上机。

- 同一方案（画布行列 + 经纬密）只认最近一次通过的样片为基准。
- 新样片与基准缩率相差超过两成时停在待复测，不能作基准。
- 画布行列或经纬密变化后，旧基准失效，不能拿来排下一匹。
- 历史样片可随时查看，重排必须选中有效基准。

## 文件结构

- `js/shrinkage.js` — 计算规则：缩率、偏差判定、按成品尺寸反推网格。
- `js/samples.js` — 样片档案：登记、存储、基准判定与校验。
- `js/app.js` — 页面操作：画布交互与校准面板的 DOM 装配。
