# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、本地保存和导出JSON。

## 洗缩校准

- **登记样片**：按当前画布行列与经纬密记为一个方案，录入样片编号、坯布与洗后宽长，自动算出经缩、纬缩。
- **基准规则**：同一方案只认最近一次通过的样片；新样片与基准缩率的相对偏差超过两成（20%）时停在待复测，不替换基准。
- **失效规则**：画布行列或经纬密任一变化后，旧基准即失效，可查不可选，不能拿来排下一匹。
- **排下一匹**：须选当前方案的有效基准，填成品宽长，反推坯布尺寸、织造网格（经列×纬行）和纹样重复数。
- **历史样片**：全部登记记录均可查询，状态分为有效基准、基准·已失效、历史通过、待复测。

代码分三层承担：`ShrinkageRules`（计算规则，纯函数）、`SampleArchive`（样片档案，登记/基准/本地存储）、页面脚本（DOM 操作）。样片数据存于 localStorage 的 `zfl31Samples`。
